# Изменения

## 0.6.9 (2026-11-04)

- Долговременная память. Агент сам запоминает важное, без команды «запомни»: о вас (имя, как с вами работать) — в общую память для всех проектов, о проекте — в память этого проекта. Записывает только по вашим словам, не больше 3 записей за задачу; ключи и пароли не сохраняются.
- Каждая запись видна в чате служебной строкой «Память · запомнил …» с кнопкой «Отменить»; клик по строке открывает новую вкладку настроек «Память» со списком записей, правкой и удалением.
- Новая запись пробная, агент опирается на неё меньше. Подтверждённой она становится, если переживёт две другие задачи или вы повторите тот же факт.
- Память занимает мало контекста: до 10 подтверждённых и 3 пробных записей на каждую память, в худшем случае около 1,8 тыс. токенов. Выключается во вкладке «Память».

## 0.6.8 (2026-11-04)

- Исходники расширения переехали в отдельный репозиторий [RuslanSinkevich/skycode](https://github.com/RuslanSinkevich/skycode). Прежний форк VS Code с историей лежит в архиве [skycode-vscode-fork](https://github.com/RuslanSinkevich/skycode-vscode-fork).
- Документация обновлена под новый репозиторий.
- Запросы к OpenRouter и регистрация MCP-клиента по OAuth указывают страницу проекта вместо несуществующего адреса `skycode-ai.local`.
- Подсказка у кнопки очистки кэша модели индексации называет правильную папку.

## 0.6.7 (2026-10-21)

- Длинные строки в таблицах и блоках кода в чате переносятся и не уходят за край панели.
- Детектор зацикливания ловит и короткую фразу, повторённую тысячи символов подряд в рассуждениях модели. Раньше такой ответ заканчивался пустым ответом провайдера.

## 0.6.6 (2026-10-20)

- Модель GigaAM скачивается готовыми файлами с Hugging Face и не требует распаковки архива. На рабочих машинах, где запрещён `tar.exe`, установка раньше падала. Архив с GitHub остался запасным путём.
- Если соединение оборвалось во время загрузки, она повторяется до трёх раз.

## 0.6.5 (2026-10-20)

- Расширение работает в VS Code 1.90 и новее (раньше требовался 1.124).

## 0.6.4 (2026-10-20)

- Пожертвования на странице «О проекте» идут через CloudTips: готовые суммы и «Другая сумма».

## 0.6.3 (2026-10-20)

- Голосовой ввод на GigaAM v3 для русского языка: текст появляется во время речи, с пунктуацией, без интернета. Движок и модель скачиваются по кнопке в настройках, вкладка «Голос». Для русского языка GigaAM выбран по умолчанию.
- Отправка сообщения во время диктовки останавливает запись и отправляет итоговый текст. Во время записи поле ввода обведено рамкой.

## 0.6.2 (2026-10-19)

- Ответ модели, оборванный по лимиту длины посреди вызова записи файла или команды, больше не исполняется. Файл не обрезается, а модель получает подсказку разбить работу на части.

## 0.6.1 (2026-10-19)

- Первый релиз через GitHub Actions: сборку и публикацию в Marketplace запускает тег `ext-vX.Y.Z`.
- Пакет называется `skycode-ai` (идентификатор `skycode.skycode-ai`), потому что имя `skycode` в Marketplace занято. Команды и панель остались `skycode.*`. История задач переносится из прежнего хранилища `skycode.skycode`.

## 0.6.0 (2026-10-19)

- Первый выпуск в Visual Studio Marketplace. Skycode теперь расширение для обычного VS Code, а не отдельная сборка редактора.
- Пакет занимает около 9 МБ вместо 168 МБ: модель эмбеддингов и `onnxruntime` в него не входят. Поиск по коду работает без индекса, векторная индексация необязательна и выключена по умолчанию.
