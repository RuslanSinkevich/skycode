# Skycode AI

**AI-агент для VS Code под ваши модели.** Подключается к корпоративному OpenAI-совместимому шлюзу (vLLM, LiteLLM), к локальной модели (Ollama, LM Studio) или к облачным провайдерам — GigaChat, YandexGPT, OpenRouter и другим. Без аккаунтов, регистрации и подписок: код уходит только в ту модель, которую вы подключили.

*AI coding agent for VS Code that works with your own models — any OpenAI-compatible gateway, local or cloud. No accounts, no subscriptions.*

![Skycode](https://ruslansinkevich.ru/img/skycode.webp)

## Возможности

- **Агент с инструментами** — ищет по коду, читает файлы и отдельные методы, правит, запускает команды. Каждое изменение видно как diff в редакторе: принять, отклонить или откатить.
- **Рассчитан на модели попроще** — Qwen и аналоги с контекстом около 100 тысяч токенов. Skycode останавливает зацикленный ответ, бережёт контекст и подсказывает модели продолжить, если она объявила шаг и забыла его сделать.
- **Вкладки и очередь** — несколько задач параллельно, следующие сообщения ждут в очереди, пока агент работает.
- **Схемы и таблицы в чате** — схемы связей (Mermaid) и графики прямо в ответе; таблицу можно скопировать в Word или Excel.
- **Контекст под контролем** — кольцо показывает, сколько контекста занято и на что; длинную сессию можно сжать одной кнопкой.
- **MCP** — подключение внешних инструментов по Model Context Protocol.

## Быстрый старт

1. Откройте панель **Skycode** на боковой панели.
2. Шестерёнка → вкладка **Провайдер** → **OpenAI Compatible**.
3. Укажите адрес шлюза (например `https://llm.company.ru/v1`), ключ API и имя модели.
4. Задайте размер контекста модели и напишите задачу в чат.

Облачные провайдеры — в том же списке, в разделе «Ещё провайдеры».
