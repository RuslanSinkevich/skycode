# Просмотр изменений

Агент записывает правки прямо в файлы. Каждая правка остаётся непринятой, пока вы её не примете или не отклоните. Для каждого сообщения пользователя сохраняется снимок файлов, поэтому изменения можно откатить. Код: `extensions/skycode/src/core/diff-v2/`. Панель в чате: `webview-ui/src/components/chat/pending-changes/PendingChangesBar.tsx`.

## Что видно пользователю

### В редакторе

Подсветку рисуют стандартные декорации VS Code (`ui/HunkDecorations.ts`). Собственных кнопок и вставок в редакторе нет.

- **Добавленные и изменённые строки:** зелёный фон на всю строку (цвет темы `diffEditor.insertedLineBackground`) и метка на полосе прокрутки.
- **Место удаления:** тонкая красная черта над следующей строкой (под последней строкой, если удалено в конце файла) и метка на полосе прокрутки. Сами удалённые строки в редакторе не показываются.
- **При наведении** на подсвеченное место виден удалённый текст («Было до агента (N стр.)», до 20 строк) и ссылка «Открыть сравнение».
- **Кнопок «Принять» и «Отклонить» в редакторе нет.**

Если для файла открыто окно сравнения «до агента ↔ сейчас», собственная подсветка в нём отключается, чтобы не дублировать подсветку VS Code.

### Сочетания клавиш и команды

Сочетания работают, когда в редакторе есть непринятые изменения.

| Действие | Windows и Linux | macOS | Команда |
|---|---|---|---|
| Принять изменение под курсором | `Ctrl+Shift+Y` | `Cmd+Shift+Y` | `skycode.diff.acceptCurrent` |
| Отклонить изменение под курсором | `Ctrl+Shift+N` | `Cmd+Shift+N` | `skycode.diff.rejectCurrent` |
| Следующее изменение | `Alt+]` | `Alt+]` | `skycode.diff.nextHunk` |
| Предыдущее изменение | `Alt+[` | `Alt+[` | `skycode.diff.prevHunk` |

Переход между изменениями идёт по файлам в алфавитном порядке: когда в текущем файле изменения кончились, открывается следующий файл с изменениями.

Только через палитру команд:

| Команда | Что делает |
|---|---|
| `skycode.diff.acceptAllInFile` | Принять все изменения в текущем файле |
| `skycode.diff.rejectAllInFile` | Отклонить все изменения в текущем файле |
| `skycode.diff.openBaselineDiff` | Открыть окно сравнения для файла |
| `skycode.diff.clearAll` | Забыть все ожидающие изменения. Файлы не меняются |

### В чате

Над полем ввода стоит панель непринятых изменений:

- сводка «N файлов +X −Y»;
- стрелки перехода к предыдущему и следующему изменению;
- «Отменить»: отклонить все изменения (с подтверждением «Отклонить все изменения?»);
- «Принять»: принять все изменения.

Клик по сводке раскрывает список файлов. У каждого файла при наведении появляются кнопки «принять» и «отклонить» для этого файла. Клик по имени файла открывает окно сравнения.

### Окно сравнения

Стандартное окно сравнения VS Code с заголовком «имя файла (до агента ↔ сейчас)». Слева базовое состояние файла (до правок агента или до последнего принятого изменения), справа текущий. В нём работают штатные стрелки отката по кускам. Для нового файла (его до агента не было) окно сравнения не открывается, вместо него открывается сам файл с подсветкой. Для удалённого агентом файла открывается только левая сторона.

## Откат по сообщениям

Перед первой правкой файла в рамках сообщения пользователя сохраняется снимок содержимого. Все правки одного сообщения образуют группу (`ResponseGroup`). Если удалить сообщение в чате или повторить его, `DiffSystem.rollbackFromMessage()` находит группы этого сообщения и более поздних, восстанавливает файлы из снимков и помечает их изменения как отклонённые. Группы более ранних сообщений остаются нетронутыми.

## Устройство

```
DiffSystem — core/diff-v2/DiffSystem.ts (фасад)
├── storage/
│   ├── DiffStore               группы, записи об изменениях файлов, куски (workspaceState)
│   ├── FileSnapshotStorage     снимки файлов на диске
│   └── PendingChangesStorage   мост к панели в чате
├── engine/
│   ├── HunkApplier             запись правки в файл, создание куска
│   ├── HunkReverter            принять и отклонить
│   ├── PositionTracker         пересчёт номеров строк после правок
│   └── SystemEditGuard         отличает записи системы от ручных правок
└── ui/
    ├── HunkDecorations         подсветка в редакторе
    └── KeyboardNavigation      переходы и команды принять/отклонить
```

Инструменты записи (`write_to_file`, `replace_in_file`, `replace_text`, `delete_block`, `apply_patch`) вызывают `replaceLines`, `deleteLines` и `addLines`. Далее:

1. Если файл открыт с несохранёнными правками, он сохраняется. Если снимка файла для этой группы ещё нет, он создаётся.
2. `applyWithOverlapCheck`: если новая правка пересекается или касается непринятого куска в том же месте, старый кусок сначала отклоняется (снизу вверх), потом применяется новая правка. Если модель более 5 раз подряд переписывает одно и то же место, правка блокируется с ошибкой.
3. `HunkApplier` записывает правку и берёт список удалённых строк из реального содержимого файла, а не из того, что передал вызывающий код.
4. Хранилище сообщает об изменении, декорации и панель в чате перерисовываются.

**Принять** не меняет файл (новый текст уже на месте): кусок помечается принятым, а базовое состояние файла для окна сравнения обновляется до принятого. Когда у файла не остаётся непринятых кусков, его снимок удаляется. **Отклонить** возвращает исходные строки куска и сдвигает номера строк оставшихся кусков. Статус группы выводится из статусов кусков: все отклонены, часть отклонена или ожидает.

## Ручные правки и git

- Если вы правите текст внутри непринятого куска, его границы обновляются (`handleManualEdit`).
- После коммита или смены HEAD в git непринятые изменения сверяются с файлом. Если файл в git совпадает с тем, что записал агент, изменения принимаются автоматически (уведомление «подтверждены автоматически — закоммичены в git»). Если git переписал файл, кусок закрывается без правки файла. Если нет данных для сравнения, изменения остаются непринятыми.

## Окружение

Для работы нужен только стандартный API VS Code (`createTextEditorDecorationType`, `TextDocumentContentProvider`, `vscode.diff`). Предложенные API не используются.

## Тесты

Тесты лежат в `core/diff-v2/__tests__/`, `core/diff-v2/*/__tests__/` и запускаются командой `npm run test:unit` из `extensions/skycode`.
