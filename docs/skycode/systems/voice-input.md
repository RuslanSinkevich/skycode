# Голосовой ввод

Диктовка в поле ввода чата. Распознавание локальное: звук не покидает компьютер. Для русского языка используется GigaAM v3 с пунктуацией на sherpa-onnx, текст появляется во время речи. Для остальных языков используется whisper.cpp, текст появляется после остановки записи.

Код: `extensions/skycode/src/services/dictation/`, настройки: `src/shared/DictationSettings.ts`, кнопка записи: `webview-ui/src/components/chat/VoiceRecorder.tsx`, вкладка настроек: `webview-ui/src/components/settings/sections/VoiceSection.tsx`.

## Включение

Настройки Skycode, вкладка **«Голос»**:

1. Включить «Включить голосовой ввод» (по умолчанию выключено).
2. Выбрать язык распознавания (по умолчанию русский).
3. Выбрать микрофон. «Автоматически» оставляет выбор системе. Список можно обновить.
4. Выбрать качество. Для русского доступен «Русский — GigaAM v3», для всех языков «Базовое», «Стандартное» и «Улучшенное» (whisper.cpp: tiny, base, small).
5. Нажать «Загрузить». Один раз скачиваются компоненты (для GigaAM около 230 МБ). Кнопка «Переустановить» удаляет и скачивает их заново.

После этого в поле ввода появляется кнопка записи. Одна запись длится не больше 5 минут.

Если выбран GigaAM, но платформа его не поддерживает, пункт в списке недоступен. Поддерживаются: Windows x64, macOS arm64 и x64, Linux x64 и arm64. При смене языка с русского на другой модель переключается на whisper.

## Как работает GigaAM

```
микрофон → ffmpeg (PCM 16 кГц, моно) → воркер (worker_thread)
                                         ├── Silero VAD: деление речи по паузам
                                         └── GigaAM v3 (sherpa-onnx): распознавание
                                              ↓
                              живой текст → поле ввода чата
```

- `AudioRecordingService` запускает ffmpeg и получает от него сырой звук.
- `SherpaDictationService` передаёт звук в воркер `sherpa-dictation-worker`. Распознавание одного куска занимает порядка полусекунды, поэтому оно вынесено из процесса расширений.
- `DictationAssembler` собирает текст. VAD режет речь по паузам (тишина от 0,4 с; речь не длиннее 20 с). Законченная фраза фиксируется. Текущая недосказанная фраза пересчитывается примерно каждые 0,7 с.
- Текст вставляется в позицию курсора. Всё, что было до и после курсора в момент старта записи, сохраняется.
- Воркер с моделью остаётся в памяти между записями (загрузка модели порядка секунды) и выгружается после 10 минут простоя.
- Ориентир скорости по замерам автора проекта: 17 секунд речи на обычном процессоре распознаются примерно за 1 секунду.

### Отправка во время диктовки

Кнопка отправки и `Enter` во время записи останавливают запись, дожидаются итогового текста и отправляют сообщение.

## Какие файлы скачиваются

Папка: `voice-sherpa/` в данных расширения.

| Что | Откуда | Проверка |
|---|---|---|
| Среда выполнения sherpa-onnx (`sherpa-onnx-node` и пакет под платформу) | npm, `registry.npmjs.org` | sha512 (значения зафиксированы в коде) |
| Файлы модели GigaAM v3: `encoder.int8.onnx`, `decoder.onnx`, `joiner.onnx`, `tokens.txt` | Hugging Face, закреплённая ревизия | sha256 |
| Запасной источник модели | архив `.tar.bz2` с GitHub (релиз sherpa-onnx), распаковка системным `tar` | sha256 |
| Silero VAD (`silero_vad.onnx`) | GitHub (релиз sherpa-onnx) | sha256 |
| ffmpeg | см. ниже | sha256 для загружаемого |

Особенности загрузки (`sherpa/downloadPinned.ts`):

- файл пишется во временное имя и переименовывается только после совпадения хеша; при несовпадении загрузка падает;
- редиректы обрабатываются; таймаут считается по простою (120 с без данных), а не по общему времени;
- при обрыве соединения загрузка повторяется до трёх раз; несовпадение хеша и HTTP-ошибки не повторяются;
- общий прогресс считается по размеру файлов.

Основной источник модели — Hugging Face, потому что архив `.tar.bz2` распаковывается системным `tar`, который на корпоративных компьютерах иногда заблокирован. GitHub-архив используется, если Hugging Face недоступен.

**ffmpeg.** Сначала ищется уже установленный: папка whisper-сервиса в данных расширения, собственная папка `voice-sherpa/ffmpeg/`, затем `PATH` и типовые каталоги. Если не найден, скачивается сборка `ffmpeg-static` с GitHub.

## Whisper

Для языков, кроме русского (и для русского, если выбрано «Базовое», «Стандартное» или «Улучшенное»), используется `whisper-cli` из whisper.cpp:

| Качество | Модель | Размер архива |
|---|---|---|
| Базовое | tiny | около 75 МБ |
| Стандартное | base | около 142 МБ |
| Улучшенное | small | около 466 МБ |

Архивы с программой и моделью скачиваются из хранилища проекта (`storage.yandexcloud.net/skycode-releases`) в папку `whisper/` данных расширения. Запись идёт в файл, после остановки звук приводится к 16 кГц моно и распознаётся локально. Живого текста нет.
